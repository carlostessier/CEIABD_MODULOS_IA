# Módulo 2: Programación para IA

En este módulo se presentan las bases de programación necesarias para el desarrollo de proyectos de inteligencia artificial. Incluye desde la introducción a Python hasta librerías de manipulación de datos y visualización, así como conceptos de redes neuronales y machine learning básico.

## Contenido de las UT

- **UT1_IntroduccionPython**: configuración del entorno, sintaxis básica, tipos de datos, estructuras de control y funciones.
- **UT2_NumPyPandas**: uso de las librerías NumPy y Pandas para el cálculo numérico y la manipulación de datos tabulares.
- **UT3_Visualizacion**: creación de gráficos con Matplotlib, Seaborn y Plotly.
- **UT4_RedesNeuronales**: conceptos básicos de redes neuronales y flujo de datos para modelos de deep learning.
- **UT5_MachineLearningBasico**: técnicas fundamentales de machine learning, preprocesado y evaluación de modelos.

Cada UT contará con subcarpetas `notebooks/` (cuadernos de clase), `datasets/` (conjuntos de datos), `ejercicios/` (prácticas y soluciones) y `recursos/` (hojas de trucos, PDFs).
