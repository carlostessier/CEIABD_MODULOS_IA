# UT1 Tipos de IA

Esta unidad incluye los notebooks y recursos relacionados con los tipos de inteligencia artificial y los sistemas basados en reglas (SBR).

## Materiales

- `notebooks/`: cuadernos de Jupyter que introducen los conceptos de sistemas basados en reglas, ejemplos con el dataset Iris, arquitecturas RNN y autoencoders.
- `datasets/`: datos de ejemplo utilizados en los notebooks.
- `img/`: imágenes y figuras utilizadas en las explicaciones.
- `ejercicios/`: ejercicios y soluciones para que practiques.

Sigue el orden numérico de los notebooks (01_, 02_, etc.) para un aprendizaje guiado.
