# Estructura del repositorio

Este documento describe la organización del repositorio `CEIABD_MODULOS_IA` después de la reestructuración para el curso 2024‑2025. Los materiales se agrupan en tres módulos, cada uno con sus unidades temáticas (UT) bien definidas. Los notebooks, datasets, modelos e imágenes se guardan en carpetas separadas para mantener un orden claro.

## Módulo 1 – Modelos de IA
Contiene contenidos sobre tipos de inteligencia artificial, procesamiento del lenguaje natural, robótica y detección de pose. Cada UT tiene su propia carpeta (`UT1_TiposIA`, `UT2_NLP`, `UT3_Robotica`, `UT4_DeteccionPose`) con subdirectorios `notebooks`, `datasets`, `img`, `models` y `ejercicios`.

## Módulo 2 – Programación para IA
Introduce la programación en Python y las bibliotecas básicas utilizadas en IA: NumPy, Pandas, Matplotlib/Seaborn/Plotly y redes neuronales básicas. Incluye UT específicas para cada tema y carpetas adicionales para ejercicios, procesado de imagen y notebooks de PyTorch.

## Módulo 3 – Sistemas de aprendizaje automático
Recoge los temas de aprendizaje supervisado (regresión, árboles de decisión, KNN, Naive Bayes, SVM), aprendizaje no supervisado, aprendizaje por refuerzo y redes neuronales, además de un proyecto final. Cada UT dispone de sus propios notebooks y recursos.

## Otras carpetas
- `common_datasets`: conjuntos de datos reutilizables por diferentes módulos.
- `docs`: material teórico, guías y hojas de referencia.
- `requirements.txt` y `requirements.lock.txt`: listado de dependencias y sus versiones exactas para reproducir el entorno.
- `LICENSE`: licencia del repositorio.

Usa esta estructura para navegar fácilmente por los contenidos y localizar las prácticas y recursos de cada unidad temática.
